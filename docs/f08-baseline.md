# F08 native developer-experience baseline

The accepted D21 procedure measures native retained-data startup, authenticated registration/read journeys and occupied-port recovery. The harness and protocol are committed before executing trials; observations and raw artifacts will be added after the run. No numerical performance target is defined.

See [procedure](baseline-procedure.md), [decision D21](decision-log.md#d21--f08-measured-baseline-scope-and-protocol) and [unmeasured human worksheet](baseline-human-worksheet.json).
